# CUE 0.1.3: аудит перед чистым релизом

5 ноября 2026. Только чтение: в коде ничего не менялось. Проверено на установленной 0.1.3: распознавание речи — Parakeet Ultra на этом компьютере, чистка — в облаке (Anthropic).

## Короткий вывод

Код в хорошем состоянии: clippy без единого предупреждения, TypeScript без ошибок, 413 тестов UI и 1249 тестов Rust зелёные, нет TODO, мёртвого кода и неиспользуемых зависимостей. Главное, что нужно сделать перед публикацией:
1. Привести документы к коду: ARCHITECTURE.md и README.md.
2. Дополнить лицензии сторонних библиотек.
3. Убрать из кода ссылки на внутренние спецификации, которых не будет в публичном репозитории.

Главные резервы оптимизации:
- 1 ГБ памяти, который всё время держит модель распознавания речи;
- около 10 % ядра, на которые WebView2 тратит процессор в простое.
