Portable as it is

  • cue-core: Flow, refine checks, translation rules, speech pieces, habits, corrections, history, settings, usage
  • Network engines: Claude, OpenRouter, the chat services, Ask, key checks, Hugging Face, downloads
  • Speech: Parakeet's mel features and TDT decoding; Opus and Ogg are pure Rust
  • Local cleanup: the pieces, deadlines and grammar (llama.cpp can use Metal on a Mac)
  • All the TypeScript pages: the Drop, the card, the main and welcome windows
  • The leak scan of a build

Keys move from Credential Manager to the Keychain through the same keyring crate, and autostart becomes a LaunchAgent: main.rs already passes the launcher kind.
