# Language: Russian or English per dictation

The owner speaks either Russian or English in a dictation, never both mixed (said 01.11.2026). Detecting the language
of each dictation must be flawless; mixed-language handling is not a priority.

When adding or tuning a speech engine, design for one language per dictation and test detection on short Russian and
English phrases; don't spend effort on code-switching. See ARCHITECTURE, "One language a dictation".
